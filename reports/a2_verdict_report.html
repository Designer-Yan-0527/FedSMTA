一、研究问题与审计发现

  • 对象：FedTA（CVPR 2025）——prompt + key + Tail Anchor 架构的联邦持续学习方法。
  • 审计结论：官方评估协议（对角线 Table 1 + 仅监控 task 0 的 KRt）系统性掩盖了 F = 18.89pp 的标准遗忘（seed 42，F = 对角线均值 93.73 − 旧任务终值均值 74.84）。
  • 实现方式：不改训练、只改度量——对每个任务结束时做全任务精度矩阵评估（RNG 快照/恢复，不扰动训练流），并以结构化 train_log.csv 分离记录聚合前/广播后两个阶段。
  • 复现情况：与官方 FedTA 仓库逐位一致（Gate 0A，D=0）；三 seed（42/1999/2025）基线全部完成，核心签名（表观遗忘被对角线协议掩盖、事件驱动非单调崩塌、知识未擦除）全部复现。

人话版：官方报成绩只看“刚学完新任务那一刻”，相当于考完立刻对答案；我们按持续学习的标准口径重算，发现 FedTA 实际忘了近 19 个百分点——这个问题在三个随机种子上都存在，只是轻重不同，被论文的报数方式系统性藏住了。

人话版：把新旧的“查找表”（key/anchor）和“说明书”（prompt）拆开排列组合一测：全用旧零件，旧任务精度 100% 回来了——知识根本没丢，是新旧接口装不上。统计上最可疑的 anchor 最后被干预实验洗清了嫌疑：它只是跟着真凶一起动的“影子”，真凶是负责路由的 key。

人话版：图上一眼可见：红柱（遗忘）从 18.89 掉到 7.11，唯独 anchor 臂反冲到 24.44——这根“反常的柱子”本身就说明了因果方向。

六、T0 / T1 精度轨迹（任务推进过程）

control 呈 V 型崩塌后部分回弹（TKR>100% 的回弹来源）；anchor 臂早期即深度塌陷；key/both 臂全程平稳，无崩塌点。

九、接口遗忘分解（Interface Forgetting，新指标）

统一定义（pi = Ai,i 刚学完精度，bi = 基线终态精度，ri = A1 换回历史接口后的精度）：Fi = (ri − bi) + (pi − ri)。前项为 A1 干预下可恢复的遗忘份额（interface-recoverable under A1），后项为残余遗忘（知识本体真实损失）。ri 取自 A1 快照评估（seed 42）。

归因边界：A1 换回的是 key+anchor 整体接口世代，故该份额只证明"接口级可恢复"，不单独指认 key——"key 为主通道"的因果结论由 A2 四臂干预（§三）独立确立，两项证据互补而非互相推出。

十一、工程实现与可信度保障

  • Phase 0 三 Gate（全部 PASS）：0A 与官方 FedTA 逐位一致（D=0）；0B 断点续训等价（checkpoint 含 RNG 状态 + outer_split_manifest，划分不一致拒绝恢复）；0C 观察者不变性（插桩 RNG 中立，ON/OFF 轨迹逐位相同）。通过后 git tag 冻结基线，fedta 路径只读。
  • A2 实现（零侵入）：所有代码严格在 method=='fedta_a2' 分支守卫内。三个机制：(1) 任务开始时用当前 key 对已完成任务特征做 top-1 路由，计算涌现保护集（全程 RNG 中立）；(2) 每次 optimizer.step() 后 post-step restore 受保护 slot —— 等价于“冻结 + weight decay 豁免”，不改官方 Adam 构造、不改任何训练损失；(3) fail-closed resume：保护快照持久化为 a2_state，缺字段 / arm 不匹配 / task_id 不符一律 RuntimeError 拒绝。
  • A1 实现：纯推理脚本，把旧任务的 key/anchor 换回 task_XX_end.pth 中的历史世代；评估顺序与种子约定（9700+100·cid+task）与 2×2 诊断逐位一致，使 delta 精确消掉 batchwise_prompt 噪声。
  • 回归测试 T1/T2/T3（全绿后才放行四臂）：T1 = A2 resume 逐位等价；T2 = fail-closed 拒绝路径（arm 不匹配 / 缺 a2_state / 跨 method）；T3 = A1 与 2×2 组合结果逐位相等。
  • 实现哲学：训练侧零侵入、度量侧全插桩（RNG 中立）、诊断靠消融组合、修复靠最小干预、可信度靠 fail-closed + 逐位回归测试——干预越小，机制证明强度越高。

人话版：动手之前先证明三件事：我们的“尺子”和官方量出来的一模一样（逐位一致）、中途暂停再续跑不改变结果、旁边观察不干扰训练。之后所有改动都锁在一个独立开关后面，官方基线一行没动——所以报告里的任何差异只能来自干预本身，不可能是“我们改坏了别的地方”。

十三、结论与下一步

  1. 方案成立（三 seed 定稿 + 跨数据集平移）：key 冻结将遗忘均值削减 67%（F 11.13±6.77 → 3.69±3.03，逐 seed 62%/79%/68%），AA +5.73pp（85.07→90.80），可塑性代价 0.10pp；零通信、零回放、在线、不要求推理时任务身份，可直接部署。seed 间波动压缩近半（旧任务 std 6.89→3.57）。ImageNet-R 平移成立：F 2.66→0.90（−66%，与 CIFAR 削减比例一致）、AA +2.31pp、可塑性 +1.00pp（零代价），三个因果签名全部复现。
  2. 因果闭环：key 路由漂移是损伤主通道；anchor 是知识载体 + 共适应缓冲（冻结有害，F 24.4）；FE 相关性指向 anchor 只因它是共漂移的影子。
  3. 残余通道：距 A1 上界剩 ~5pp（A2 捕获 68%），来自 prompt 漂移与个别 client 的路由碰撞——论文“残余失效模式”一节素材。
  4. ImageNet-R 平移（已完成）：修正协议 p40 两臂终局判决见第十二节——F 削减 66%、旧任务 +2.76pp、AA +2.31pp、可塑性 +1.00pp，5 client 无一例外；A2-key 在轻遗忘数据集上同样成立且零代价。
  5. 下一步（论文六环主线）：① 接口遗忘分解（seed 42 已完成，1999/2025 补 A1 后入表）→ ② key 侧跨世代失配因果证据（已完成）→ ③ FCILPT 移植验证家族级现象 → ④ A3 兼容性保持接口适应（功能级约束：同一参照输入下对齐两代路由行为；soft-freeze 仅作消融）→ ⑤ 长序列（ImageNet-R 10 任务，暴露 hard freeze 塑性天花板）→ ⑥ SOTA 对比表 + 论文初稿。A4 历史世代自动检索留给下一篇。
