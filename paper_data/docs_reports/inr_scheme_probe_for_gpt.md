# FedSMTA §34 INR 方案有效性探针结果汇总（ImageNet-R, seed 42, 125 cell 全量）

> 用途：交给外部模型做交叉审查。目标读者无项目上下文，本文自包含。
> 姊妹篇：`b0_results_for_gpt.md`（CIFAR100 的 B0 判决，已 GREEN）。

## 1. 背景与问题

- 基础系统：FedTA（CVPR2025），联邦持续学习，ViT prompt + per-client Tail_Anchor 读出头；5 客户端 × 5 任务 × 每任务 5 轮（ImageNet-R，p40 协议：每任务 40 私有类）。
- CIFAR100 上已验证的结构（DSAR）：**B_t**（label-free ridge 桥，把广播后表示 z⁺ 拉回出生表示 z⁻）+ **L_t**（低秩 residual adapter，有标签 CE 拟合）。CIFAR 的 B0 判决 GREEN：免标签桥追平有标签重训（ρ_birth ≈ 1）。
- 问题：CIFAR 的配方（γ*=0.396, rank 8, B+L, identity guard）**直接搬到 INR 上信号失效**——INR 上重新校准的 γ*=2.06（是 CIFAR 的 5 倍），且各任务间桥系数方向不一致。因此需要回答：**在 INR 上，哪个方案（B、L、组合）真正有效？**
- 本实验 = **方案有效性探针（scheme probe）**：在一条与官方训练轨迹一致的 INR capture run（125 cell，每轮 broadcast 边界缓存 z⁻/z⁺ 全行 + 出生头状态）上，**零训练-run 离线 replay** 完整方案网格。所有评估用**部署口径**：z⁺ 测试行 → 出生头（M2' refit head，eval dropout off）Tail_Anchor 读出，anchor 路由看校正后的 z。
- 指标：task-end（每任务最后一轮，25 cell）pooled delta（pp）为主排名键；mean = 全 125 cell 均值。参照锚 ref_zm = z⁻ 读出 − z⁺ 读出（广播损伤总量）。
- **论文定位（作者立场）**：论文方案 = B_t + L_t（改造训练/读出路径的结构创新），**对比对象与部署口径 = baseline（官方联训头）**。M2'/M2''（重训读出头类方案）不改造训练流程，不构成结构创新，仅作诊断对照与 ceiling 锚。因此本探针的 M2' 口径数字是**结构可行性证据**；论文口径（联训头）的数字待补测——z± 表示行与读出头解耦，若 capture checkpoint 存有每轮联训头，可离线换头重读补齐（见问题 1b）。

## 2. 误差源结构（为什么 CIFAR 配方在 INR 失效）——注意口径限定

本 capture run 是 **M2matched** 口径：读出头 = M2' refit head（每轮已用标签 refit 过的"修好的头"）。L 与 M2' 属同类修理（都用标签对齐读出，L 是低秩廉价版）——**在修好的头之下，L 没有病可治**。以下失配测量均在此口径下：

```
z⁺ 出生头读出           83.74   （off，起点）
z⁻ 出生头读出           85.10   （ref_zm，损伤锚 → 广播损伤 = +1.36pp mean）
离线重训上限（M2''）     85.10   （Stage 0 preview ceiling）
```

**z⁻ 读出 ≈ 重训上限（85.10 vs 85.10）→ 在 M2' 读出口径下"读出失配"≈ 0，唯一误差源是广播损伤。**

**口径警示（重要）**：本探针所有 L 判负结论只在这一口径下成立。若部署读出头是 baseline 联训头（未 refit），失配空间未知，L 是否有效**未测**。对称地，CIFAR 上"L 有效 +0.5~1pp"是在联训头口径下测的——**两个数据集的 L 结论测于相反的口径，不能互相印证**（见问题 1/1b）。

## 3. 第一轮：完整方案网格（L 臂 × B 臂 × 组合）

### L 臂（生产配方：z 基底 × rank × CE guard）——在 M2' 读出口径下全部无效

| 配置 | te pooled | mean | CE guard active |
|---|---|---|---|
| L16_zp + CE guard（§34.6a R0 方案） | +0.05 | +0.00 | 6% |
| L16_zp 无条件部署 | +0.22 | +0.41 | — |
| L32_zp 无条件部署 | +0.13 | +0.30 | — |
| L*_zm（CIFAR 生产语义基底） | −0.07 ~ −1.34 | 全负 | — |

- CE guard 在 94% 的 cell 上把 L 拦回 identity（校准行 CE 差 median +0.083，L 明显更差）。
- 无条件部署也只有 +0.22pp，远低于 +0.8pp 门；z⁻ 基底（CIFAR 语义）全负。
- Stage 0 preview 里 L 的"68% 跨度修复"用的是 z⁻ 基底 + 200ep full-batch + 无 guard + 在 z⁻ 上评估——**preview 结论不迁移到部署口径**。
- 组合链（B8 后接 L16）：+0.29 < B8 单独 +0.48，负贡献，与 §34.6 判定一致。

### B 臂（label-free）——有效，成为 INR 主方案

| 配置 | te pooled | mean |
|---|---|---|
| B16(γ*_INR=2.06) | +0.69 | +0.61 |
| B8(CIFAR γ*=0.396) | +0.63 | +0.57 |
| B16(GCV 选 λ) | +0.12 | +0.11 |
| B16(λ=0 无 shrink) | −7.69 | −6.37 |

- 固定 γ ≫ GCV ≫ λ=0；INR 上 GCV 选 λ 无效。
- 修复率：+0.69 / 1.14（te 口径损伤锚）≈ 60%。
- 所有 B 拟合全部通过 cal-MSE guard（无一被拦）。

## 4. 第二轮：B 网格细化（rank × γ）

te pooled（pp），完整 4×5 网格：

| rank \ γ | 0.4 | 0.8 | 2.06 | 4 | 8 |
|---|---|---|---|---|---|
| 8 | 0.64 | 0.56 | 0.48 | 0.58 | 0.42 |
| 16 | 0.59 | 0.74 | 0.69 | 0.66 | 0.51 |
| 24 | 0.74 | **0.85** | 0.63 | 0.57 | 0.65 |
| 32 | 0.75 | 0.80 | 0.69 | 0.58 | 0.59 |

两个发现：

**发现 1：rank 与 γ 有交互（两重正则的总强度匹配）**
低 rank 需要大 shrink（r8 最优 γ≈0.4-2），高 rank 需要小 shrink（r24 最优 γ≈0.8）。γ*_INR=2.06 当年是按 B8 口径的 GCV median 冻结的，rank 提高后最优 γ 下移——**γ* 是 rank 的函数**。

**发现 2：B24/γ0.8/mse-guard 是区域峰，且 guard 出现真实正贡献**
- B24/γ0.8：te +0.85 / mean +0.75；邻域（B32/γ0.8=0.80、B24/γ0.4=0.74、B24/CIFARγ=0.74、B32/γ0.4=0.75）全在 0.74–0.85 平台上，非孤峰。
- guard 分布：22/125 被拦回 identity（20 个 = B0 已知的 c0 早期轮 + **2 个 c0 task-end**）；这 2 个新拦截正是 no-guard 版本掉分的地方（guard 版 te +0.85 vs no-guard +0.79，差的 0.06pp 全部来自拦掉这两个有害拟合）。
- te cell 级：16/25 为正，median +0.95，min −1.44，max +3.44；**五个 task 的 te 均值全部为正**（+0.25/+1.28/+0.79/+0.70/+1.20）。
- 全 125 cell 均值的 rank 曲线：r8 0.60 → r16 0.63 → r24 0.75 → r32 0.73（与 te 口径同峰）。

修复率：0.85 / 1.14 ≈ **74%**（task-end 口径）。

## 5. 判读与论文故事

- **INR 上 L 撤出部署（R0 证伪，M2' 读出口径下；baseline 口径见问题 1b），B-only 为 INR 方案**。论文叙事：两模块各自修一个正交误差源（B 修广播损伤、L 修读出失配），label-free guard 自动诊断每个数据集/任务上哪个误差源存在——CIFAR 两者并存 → B+L 双激活；INR（M2' 口径）失配 ≈ 0 → CE guard 自动关 L（active 6%）、B 独挑。**guard active rate 本身是"机制正确诊断误差源"的证据**，INR 上 L 关闭不是方法失效而是诊断正确。
- 诚实声明（winner's curse）：+0.85 是 60 配置网格的 max；邻域均值 ~0.75–0.80。正式冻结应按"平台 + 交互规律"论证，不按单点 max。

## 6. 口径说明与遗留

- 全部数字 = 出生头读出的离线 replay（M2' head，eval dropout off），**不是训练管线正式 run**；capture 只含当前任务行，**历史任务迁移臂（k<t, B-only）尚待 GPU extract 验证**。
- z_ref 不变性门：两轮均 PASS（125/125）。
- z⁻ = broadcast 前出生表示；z⁺ = broadcast 后表示；cell = (round, client)；te = task-end。
